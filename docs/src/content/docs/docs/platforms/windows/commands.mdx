These examples cover Windows package commands. See the [CLI reference](/docs/cli/) for shared commands and options.

## `init`

`init` prepares Outfitting on this machine and checks the selected source. It does not change installed packages.

```sh
outfitting-manager init
```

## `apply`

`apply` installs packages declared by the selected profiles' WinGet and optional Scoop lists. Use `--winget-only` to skip Scoop. `--prune` also removes Outfitting-managed packages that are no longer declared.

```sh
outfitting-manager apply --profile work,personal
outfitting-manager apply --winget-only --profile work
```

## `diff`

`diff` compares installed WinGet and Scoop packages with the selected profiles without changing the system.

```sh
outfitting-manager diff --profile work,personal
```

## `update`

`update` upgrades installed packages through one manager. Choose either WinGet or Scoop. It does not install packages missing from the selected profiles; use `apply` for that.

```sh
outfitting-manager update --package-manager winget
outfitting-manager update --package-manager scoop
```

## `winget`

### `install`

Install a package by its WinGet ID.

```sh
outfitting-manager winget install Git.Git
```

### `uninstall`

Remove a package by its WinGet ID.

```sh
outfitting-manager winget uninstall Git.Git
```

## `scoop`

### `install`

Install a package by its Scoop name.

```sh
outfitting-manager scoop install git
```

### `uninstall`

Remove a package by its Scoop name.

```sh
outfitting-manager scoop uninstall git
```
