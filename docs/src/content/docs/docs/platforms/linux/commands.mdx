These examples cover Linux package and Home Manager commands. See the [CLI reference](/docs/cli/) for shared commands and options.

## `init`

`init` prepares Outfitting on this machine and checks the selected source. It does not change installed packages or activate Home Manager.

```sh
outfitting-manager init
```

## `apply`

`apply` installs packages declared for the selected profile using apt or pacman. Use `--prune` to remove Outfitting-managed packages no longer declared.

```sh
outfitting-manager apply --profile workstation
outfitting-manager apply --package-manager pacman --prune
```

For offline installs, `--offline` uses cached apt packages; pacman installs are not supported. With a remote source, add `--no-refresh`.

## `diff`

`diff` compares declared native packages with installed packages without changing the system. Linux compares apt by default; use `--manager pacman` to check pacman declarations. Unrelated installed packages are ignored.

```sh
outfitting-manager diff --profile workstation
outfitting-manager diff --profile workstation --manager pacman
```

## `update`

`update` upgrades installed apt or pacman packages. It does not install packages from a profile; use `apply` for that. Offline upgrades are not supported.

```sh
outfitting-manager update --package-manager apt
```

## `nix`

Linux Nix commands build or activate the selected Home Manager profile. `build`, `test`, and `dry-run` do not activate it; `switch` does. `nix update` updates the flake inputs and activates the updated profile.

### `build`

Build the profile without activating it.

```sh
outfitting-manager nix build
```

### `switch`

Build and activate the profile.

```sh
outfitting-manager nix switch
```

### `test`

Check that the profile builds without activating it.

```sh
outfitting-manager nix test
```

### `dry-run`

Preview the profile build without activating it.

```sh
outfitting-manager nix dry-run
```

### `update`

Update flake inputs, then build and activate the profile.

```sh
outfitting-manager nix update
```

## `recover nix`

Resume an interrupted Nix profile update.

```sh
outfitting-manager recover nix
```
