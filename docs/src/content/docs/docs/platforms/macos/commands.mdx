These examples cover macOS package and Nix commands. See the [CLI reference](/docs/cli/) for shared commands and options.

## Install the CLI

```sh
curl -fsSL https://outfitting.jfa.dev/install.sh | sh
```

> **Note:** Supports Apple silicon. The installer verifies the ZIP against its SHA-256 file and installs to `~/.local/bin`. Add that directory to `PATH` if it is not already there.

## `init`

`init` prepares Outfitting on this machine and checks the selected source. It does not change Homebrew packages or activate Nix.

```sh
outfitting-manager init
```

## `apply`

`apply` installs packages declared in the selected profile's Brewfile. It does not upgrade other packages or activate Nix.

```sh
outfitting-manager apply --profile personal
```

## `diff`

`diff` compares installed Homebrew and Nix packages with the selected profile without changing the system.

```sh
outfitting-manager diff
```

## `update`

`update` upgrades installed Homebrew packages. It does not install missing Brewfile packages; use `apply` for those.

```sh
outfitting-manager update
```

## `nix`

Nix commands build or activate the selected nix-darwin system. `build`, `test`, and `dry-run` do not activate it; `switch` does. `nix update` updates flake inputs and activates the updated system. Unlike top-level `update`, it does not upgrade Homebrew packages.

### `build`

Build the system without activating it.

```sh
outfitting-manager nix build
```

### `switch`

Build and activate the system.

```sh
outfitting-manager nix switch
```

### `test`

Check that the system builds without activating it.

```sh
outfitting-manager nix test
```

### `dry-run`

Preview the system build without activating it.

```sh
outfitting-manager nix dry-run
```

### `update`

Update flake inputs, then build and activate the system.

```sh
outfitting-manager nix update
```

## `snapshot brew`

Save the installed Homebrew package list without changing installed packages.

```sh
outfitting-manager snapshot brew
```

## `recover nix`

Resume an interrupted Nix profile update.

```sh
outfitting-manager recover nix
```
