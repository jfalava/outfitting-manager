Use `config wizard` to set up this machine. Use `config manifest` to create a repository-owned `outfitting.json` file.

## `wizard`

**Syntax:** `outfitting-manager config wizard [--manifest <path>] [--strict]`

Set up or update this machine's `config.toml`. The wizard asks you to choose a source and profiles, then saves the configuration and checks the source. It may offer to install packages or activate Nix; each system change requires confirmation.

```sh
# Set up the default configuration
outfitting-manager config wizard

# Import declarations from outfitting.json in the selected source
outfitting-manager config wizard --manifest outfitting.json

# Stop setup if a package installation fails
outfitting-manager config wizard --strict

```

| Option              | Description                                                                                                                                                                                                     |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--manifest <path>` | Import profile and file declarations from a manifest in the selected source. The path is relative to the source root. Values are copied into `config.toml`; later manifest edits are not applied automatically. |
| `--strict`          | Stop at the first package installation failure instead of continuing.                                                                                                                                           |

## `manifest`

**Syntax:** `outfitting-manager config manifest [--repo <checkout>] [--force]`

Create or replace a repository's `outfitting.json` manifest. Choose the platforms, profiles, and files to include. The command checks the declared files and shows the JSON for review before writing. It does not change this machine's `config.toml` or install packages.

```sh
# Create a manifest in the current directory
outfitting-manager config manifest

# Review and replace a manifest in another checkout
outfitting-manager config manifest --repo ~/src/dotfiles --force
```

| Option          | Description                                              |
| --------------- | -------------------------------------------------------- |
| `--repo <path>` | Repository directory. Defaults to the current directory. |
| `--force`       | Allow reviewing and replacing an existing manifest.      |
