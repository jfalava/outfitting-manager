`update` upgrades packages that are already installed. It does not install packages missing from your declarations or remove undeclared packages. Use [`apply`](/docs/cli/apply/) to install declared packages and [`nix`](/docs/cli/nix/) to update or activate a Nix profile.

## macOS

**Syntax:** `outfitting-manager update [--no-push]`

Upgrade installed Homebrew packages and upload the current inventory. Use `--no-push` to skip the upload.

```sh
outfitting-manager update
outfitting-manager update --no-push
```

## Linux

**Syntax:** `outfitting-manager update [--package-manager <apt|pacman>] [--offline]`

Upgrades installed native packages. The manager is detected from the host unless selected explicitly. `--offline` refuses to run because network-free package resolution cannot be guaranteed.

| Option              | Description                                                           |
| ------------------- | --------------------------------------------------------------------- |
| `--package-manager` | Choose `apt` or `pacman`. Defaults to host detection.                 |
| `--offline`         | Refuse the update because packages cannot be safely upgraded offline. |

```sh
outfitting-manager update --package-manager apt
```

## Windows

**Syntax:** `outfitting-manager update --package-manager <winget|scoop> [--no-push]`

Upgrade packages through one selected manager. You must choose `winget` or `scoop`. Changes are uploaded by default; use `--no-push` to keep them local.

```sh
outfitting-manager update --package-manager winget
outfitting-manager update --package-manager scoop --no-push
```

| Option              | Description                                                    |
| ------------------- | -------------------------------------------------------------- |
| `--package-manager` | Choose `winget` or `scoop`. Required.                          |
| `--no-push`         | Keep update records on this machine instead of uploading them. |
