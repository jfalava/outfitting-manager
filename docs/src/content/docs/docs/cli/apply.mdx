`apply` installs packages declared for the selected profile. It does not upgrade unrelated software. Linux and Windows can also remove packages that are no longer declared; pruning is opt-in. Changes are local and are not uploaded by this command.

On Linux and Windows, installation failures are reported and other packages are still attempted by default. Use `--strict` to stop at the first failure. On macOS, `--strict` makes the command return an error if Homebrew reports an installation failure. Requested pruning is skipped after an installation failure.

### Examples

```sh
# Install packages for the configured profile
outfitting-manager apply

# Stop after an installation failure
outfitting-manager apply --strict
```

## macOS

**Syntax:** `outfitting-manager apply [flags]`

Applies the selected profile's Brewfile. Use [`nix`](/docs/cli/nix/) to build or activate its Nix configuration.

| Option                | Description                                                  |
| --------------------- | ------------------------------------------------------------ |
| `--machine-id <id>`   | Use a different machine ID for this command.                 |
| `--repo <path>`       | Use a local source directory for this command.               |
| `--profile <profile>` | Select a macOS profile instead of the configured one.        |
| `--no-refresh`        | Use the current source without refreshing it.                |
| `--strict`            | Return an error if Homebrew reports an installation failure. |

```sh
outfitting-manager apply --profile personal
```

## Linux

**Syntax:** `outfitting-manager apply [flags]`

Installs the selected profile's apt or pacman packages. The package manager is detected from the host unless you choose one.

```sh
outfitting-manager apply --package-manager apt
outfitting-manager apply --profile workstation --prune --yes
```

| Option                | Description                                                                         |
| --------------------- | ----------------------------------------------------------------------------------- |
| `--profile <profile>` | Select a Linux profile. Defaults to the configured profile or `OUTFITTING_PROFILE`. |
| `--package-manager`   | Choose `apt` or `pacman`. Defaults to host detection.                               |
| `--prune`             | Remove managed packages no longer listed for this profile.                          |
| `--offline`           | Install from the local apt cache without downloading packages.                      |
| `--yes`               | Apply the plan without asking for confirmation.                                     |
| `--no-refresh`        | Use the current source without refreshing it.                                       |
| `--if-configured`     | Skip if the profile declares no apt or pacman packages.                             |
| `--strict`            | Stop at the first installation failure.                                             |

For a remote source, use `--offline` with `--no-refresh`. Offline pacman installs are not supported.

## Windows

**Syntax:** `outfitting-manager apply [flags]`

Installs packages declared by the selected WinGet and optional Scoop profiles. You can combine Windows profiles by separating their names with commas. Changes are local and are not uploaded by this command.

```sh
outfitting-manager apply --profile work,personal
outfitting-manager apply --winget-only --profile work
```

| Option                 | Description                                                          |
| ---------------------- | -------------------------------------------------------------------- |
| `--profile <profiles>` | Select comma-separated Windows profiles.                             |
| `--repo <path>`        | Use a local source directory for this command.                       |
| `--winget-only`        | Skip Scoop packages.                                                 |
| `--prune`              | Remove managed packages no longer declared by the selected profiles. |
| `--yes`                | Apply the plan without asking for confirmation.                      |
| `--strict`             | Stop at the first installation failure.                              |
