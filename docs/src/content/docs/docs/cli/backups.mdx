**Syntax:** `outfitting-manager backups <subcommand> [flags]`

`backups` runs Rustic on macOS and Windows using the selected profile and native credentials. Linux does not include this command family. See [How backups work](/docs/backups/how-it-works/) for behavior, [Prerequisites](/docs/backups/prerequisites/) to check what you need, or [Set up backups](/docs/backups/setup/) to configure a profile.

## `doctor`

**Syntax:** `outfitting-manager backups doctor`

Show resolved configuration, hostname, repository configuration, ordered job names, job policies, retention defaults, sources, and state directory without accessing the repository or native credentials.

```sh
outfitting-manager backups doctor
```

## `status`

**Syntax:** `outfitting-manager backups status`

Read local backup receipts and print current outcomes, timestamps, and recovery anchors without accessing native credentials or the remote repository.

```sh
outfitting-manager backups status
```

## `run`

**Syntax:** `outfitting-manager backups run [--job <job>]`

Run backup jobs immediately. By default, all jobs in the active profile are executed. Does not perform retention or pruning.

```sh
# Run all backup jobs
outfitting-manager backups run

# Run one job
outfitting-manager backups run --job documents
```

| Option        | Description                                                                                                                |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `--job <job>` | Run one configured job by its Rustic snapshot `name`. Use `doctor` to see names; there are no built-in platform job lists. |

## `run-due`

**Syntax:** `outfitting-manager backups run-due`

Run daily backup jobs that are currently due and perform a weekly repository integrity check if due. Daily jobs run after 10:00 on macOS and 09:00 on Windows. Weekly checks run after Sunday 15:00.

```sh
outfitting-manager backups run-due
```

## `snapshots`

**Syntax:** `outfitting-manager backups snapshots [--job <job>]`

List repository snapshots for this host, optionally filtered by job.

```sh
# List all snapshots for this host
outfitting-manager backups snapshots

# List snapshots for a specific job
outfitting-manager backups snapshots --job photos
```

| Option        | Description                     |
| ------------- | ------------------------------- |
| `--job <job>` | Filter snapshot results by job. |

## `check`

**Syntax:** `outfitting-manager backups check [--read-data]`

Check repository metadata. Use `--read-data` to also verify file data packs.

```sh
# Check repository metadata
outfitting-manager backups check

# Check metadata and all file data packs
outfitting-manager backups check --read-data
```

| Option        | Description                                                          |
| ------------- | -------------------------------------------------------------------- |
| `--read-data` | Verify file data packs in addition to metadata. Takes longer to run. |

## `maintenance`

**Syntax:** `outfitting-manager backups maintenance [--apply] [--acknowledge-history]`

Preview or apply snapshot retention and pruning. By default, previews planned snapshot deletions while protecting accepted recovery anchors. Use `--apply` to apply retention and run two-phase pruning.

Retention inherits Rustic `[forget]` with optional per-job Outfitting counter overrides. Overlapping job-identity tags block retention. Receipts for removed jobs block `--apply` until reconciled; `--acknowledge-history` does not bypass these safeguards.

```sh
# Preview retention changes (dry run)
outfitting-manager backups maintenance

# Apply retention policy and prune data
outfitting-manager backups maintenance --apply

# Apply retention when unmanaged historical snapshots exist
outfitting-manager backups maintenance --apply --acknowledge-history
```

| Option                  | Description                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| `--apply`               | Apply retention policies and execute two-phase pruning (`prune --max-unused 10%`).                            |
| `--acknowledge-history` | Required with `--apply` if unmanaged historical snapshots exist in the repository that are not saved locally. |

## `accept`

**Syntax:** `outfitting-manager backups accept <job> <snapshot-id>`

Approve a backup candidate whose file count or processed bytes shrank by more than 50% compared to the previous anchor. Candidates flagged as `review-required` must be accepted before serving as parent snapshots or recovery anchors.

```sh
outfitting-manager backups accept documents 0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
```

| Argument        | Description                                                    |
| --------------- | -------------------------------------------------------------- |
| `<job>`         | The job name associated with the candidate.                    |
| `<snapshot-id>` | The 64-character hexadecimal snapshot ID saved in the receipt. |

## `restore`

**Syntax:** `outfitting-manager backups restore <job> <snapshot-id> <destination>`

Restore a snapshot into a new directory. The destination path must not already exist and cannot overlap any backup source path.

```sh
outfitting-manager backups restore documents 0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef ~/Desktop/restored-docs
```

| Argument        | Description                                          |
| --------------- | ---------------------------------------------------- |
| `<job>`         | The job name to restore.                             |
| `<snapshot-id>` | The snapshot ID to restore.                          |
| `<destination>` | Target directory for restored files. Must not exist. |

## `secrets`

Manage backup credentials in macOS Keychain or Windows Credential Manager.

### `secrets set`

**Syntax:** `outfitting-manager backups secrets set <name>`

Store a credential interactively in the native credential store. Prompts for the value with password masking and requires confirmation.

```sh
outfitting-manager backups secrets set repository-password
```

| Argument | Description                                                                           |
| -------- | ------------------------------------------------------------------------------------- |
| `<name>` | Credential name: `access-key`, `secret-key`, `repository-password`, or `alert-token`. |

### `secrets check`

**Syntax:** `outfitting-manager backups secrets check`

Verify required credentials in the native store without printing their values.

```sh
outfitting-manager backups secrets check
```

### `secrets import-secretstore`

**Syntax:** `outfitting-manager backups secrets import-secretstore [--vault <vault>]`

Migrate backup credentials from PowerShell SecretStore to Windows Credential Manager. Supported on Windows only.

```sh
# Import credentials from the default 'ResticVault'
outfitting-manager backups secrets import-secretstore

# Import from a custom vault name
outfitting-manager backups secrets import-secretstore --vault CustomVault
```

| Option            | Description                                                   |
| ----------------- | ------------------------------------------------------------- |
| `--vault <vault>` | PowerShell SecretStore vault name. Defaults to `ResticVault`. |

## `schedule`

**Syntax:** `outfitting-manager backups schedule --binary <path>`

Print a LaunchAgent property list (macOS) or Task Scheduler XML (Windows) configured to invoke `outfitting-manager backups run-due` using the specified executable path. The command is print-only and does not install schedules.

```sh
# Generate macOS LaunchAgent XML
outfitting-manager backups schedule --binary ~/.local/bin/outfitting-manager

# Generate Windows Task Scheduler XML
outfitting-manager backups schedule --binary "C:\Users\username\AppData\Local\Programs\OutfittingManager\outfitting-manager.exe"
```

| Option            | Description                                                               |
| ----------------- | ------------------------------------------------------------------------- |
| `--binary <path>` | Path to the installed `outfitting-manager` executable to run on schedule. |

## Global options

All `backups` subcommands accept the shared `--profile` flag:

| Option                | Description                                                                                         |
| --------------------- | --------------------------------------------------------------------------------------------------- |
| `--profile <profile>` | Select an independent backup profile from `config.toml`. Defaults to the configured backup profile. |

## Platform availability

| Platform | Available jobs                                 | Native credential store    | Schedule type  |
| -------- | ---------------------------------------------- | -------------------------- | -------------- |
| macOS    | Named snapshots in the selected Rustic profile | macOS Keychain             | LaunchAgent    |
| Windows  | Named snapshots in the selected Rustic profile | Windows Credential Manager | Task Scheduler |
| Linux    | Not supported                                  | None                       | None           |
