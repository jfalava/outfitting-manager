Use `scoop` on Windows to install or remove packages. Operations are saved and uploaded by default. Use `--no-push` to keep them on this machine.

## `install`

**Syntax:** `outfitting-manager scoop install <package...> [--no-push] [--strict]`

Install and save one or more Scoop packages. Failed installs are recorded and the remaining packages are attempted unless you use `--strict`.

```sh
outfitting-manager scoop install git
outfitting-manager scoop install git ripgrep --no-push
```

## `uninstall`

**Syntax:** `outfitting-manager scoop uninstall <package...> [--no-push]`

Remove and save one or more Scoop packages.

```sh
outfitting-manager scoop uninstall git
```
