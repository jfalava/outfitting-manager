`nix` builds and activates the profile selected in `config.toml`. It is available on macOS and Linux.

**Syntax:** `outfitting-manager nix <action> [flags]`

Successful `build`, `test`, `dry-run`, and `switch` commands publish Nix lock changes unless `--no-push` is set. `nix update` always publishes its lock.

## `build`

Build the configured system without activating it.

```sh
outfitting-manager nix build
outfitting-manager nix build --no-push
```

## `switch`

Build and activate the configured system.

```sh
outfitting-manager nix switch
```

## `test`

Check that the configured system builds without activating it.

```sh
outfitting-manager nix test
```

## `dry-run`

Show what Nix would build without activating the configured system.

```sh
outfitting-manager nix dry-run
```

## `update`

Update the flake inputs, build and activate the updated profile, then publish its lock. This command always publishes after a successful activation.

```sh
outfitting-manager nix update
```

## Options

| Option                | Available on                   | Description                                                             |
| --------------------- | ------------------------------ | ----------------------------------------------------------------------- |
| `--profile <profile>` | macOS, Linux                   | Select a profile instead of the configured one.                         |
| `--no-refresh`        | macOS, Linux                   | Use the current source without refreshing it.                           |
| `--no-push`           | macOS, Linux; not `nix update` | Skip publishing the lock after `build`, `test`, `dry-run`, or `switch`. |
| `--if-configured`     | Linux                          | Skip if the selected profile does not declare a Nix flake.              |
