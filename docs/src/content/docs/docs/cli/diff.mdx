**Syntax:** `outfitting-manager diff [flags]`

`diff` compares installed packages with the selected profile. It does not change your system. It exits with an error if packages differ or the comparison cannot be completed.

```sh
# Compare package state on this machine
outfitting-manager diff

# Print the comparison as JSON
outfitting-manager diff --json

# Linux: compare one manager for a selected profile
outfitting-manager diff --manager apt --profile workstation
```

| Option                | Description                                                        |
| --------------------- | ------------------------------------------------------------------ |
| `--manager <name>`    | Compare only one package manager.                                  |
| `--profile <profile>` | Select a profile. Windows accepts comma-separated profiles.        |
| `--offline`           | Use the available local source and skip the remote Nix comparison. |
| `--refresh`           | Linux only: refresh the source before comparing.                   |
| `--json`              | Print the results as JSON.                                         |

## Platform comparison scope

| Platform | Compared packages                                                |
| -------- | ---------------------------------------------------------------- |
| macOS    | Homebrew and Nix.                                                |
| Linux    | Declared apt or pacman packages. Unrelated packages are ignored. |
| Windows  | WinGet and Scoop.                                                |
