Use `winget` on Windows to install or remove packages. Operations are saved and uploaded by default. Use `--no-push` to keep them on this machine.

## `install`

**Syntax:** `outfitting-manager winget install <package...> [--no-push] [--strict]`

Install and save one or more WinGet packages. Failed installs are recorded and the remaining packages are attempted unless you use `--strict`.

```sh
outfitting-manager winget install Git.Git
outfitting-manager winget install Git.Git Microsoft.PowerToys --strict
```

## `uninstall`

**Syntax:** `outfitting-manager winget uninstall <package...> [--no-push]`

Remove and save one or more WinGet packages.

```sh
outfitting-manager winget uninstall Git.Git
```
