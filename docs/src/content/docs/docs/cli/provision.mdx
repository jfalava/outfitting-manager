**Syntax:** `outfitting-manager provision [flags]`

Deploy the Outfitting service, including its API and documentation site. After deployment, the command configures this machine to use the service unless you pass `--skip-configure`.

Provisioning requires a checkout of the [manager repository](https://github.com/jfalava/outfitting-manager), [Bun](https://bun.sh), and Cloudflare deployment credentials. Run `bun install` in the checkout, then run the command from the repository root. From another directory, set `OUTFITTING_IAC_DIR` to the checkout's `iac/` directory. The installed CLI binary alone does not contain the deployment stack or its dependencies.

```sh
# Deploy with the default settings
outfitting-manager provision

# Deploy using a config file and a custom hostname
outfitting-manager provision --deploy-config outfitting.deploy.json --domain manager.example.com

# Deploy without saving credentials on this machine
outfitting-manager provision --skip-configure
```

| Option                     | Description                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------ |
| `--deploy-config <path>`   | Read deployment settings from this JSON file.                                                          |
| `--domain <hostname>`      | Set the service hostname. Defaults to `outfitting.jfa.dev`; pass an empty value to use the Worker URL. |
| `--stack-name <name>`      | Set the Alchemy stack name.                                                                            |
| `--api-name <name>`        | Set the API Worker name.                                                                               |
| `--router-name <name>`     | Set the router Worker name.                                                                            |
| `--database-name <name>`   | Set the D1 database name.                                                                              |
| `--kv-title <title>`       | Set the KV namespace title.                                                                            |
| `--private-fonts <bucket>` | Set the private-fonts bucket name.                                                                     |
| `--token <value>`          | Set the API token. Defaults to the environment value or a generated token.                             |
| `--skip-configure`         | Deploy without configuring this machine to use the service.                                            |

CLI flags take precedence over environment variables and values in the deployment file. Existing installations keep their current service URL until it is changed.
