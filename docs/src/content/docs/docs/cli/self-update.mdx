---

**Syntax:** `outfitting-manager self-update` or `outfitting-manager upgrade`

Download and install the latest CLI release for your platform. This does not update your packages. `upgrade` is an alias for `self-update`.

```sh
outfitting-manager self-update
outfitting-manager upgrade
```

| Platform | Supported release |
| -------- | ----------------- |
| macOS    | Apple silicon     |
| Linux    | x64 and arm64     |
| Windows  | x64               |
