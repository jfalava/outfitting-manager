Use `sync` to save and retrieve machine state. It does not install, upgrade, or remove packages. It uses this machine's configured or derived ID; `OUTFITTING_MACHINE_ID` overrides it. Default file paths are relative to the current directory.

## `configure-worker`

**Syntax:** `outfitting-manager sync configure-worker [<url>]`

Save the service URL for later sync commands. You can also set `OUTFITTING_LOCKFILES_URL`; it takes precedence over the saved URL.

```sh
outfitting-manager sync configure-worker https://manager.example.com/api
```

## `configure-token`

**Syntax:** `outfitting-manager sync configure-token`

Prompt for and save the service token for later sync commands. You can also set `OUTFITTING_LOCKFILES_TOKEN`; it takes precedence over the saved token.

```sh
outfitting-manager sync configure-token
```

## `push`

**Syntax:** `outfitting-manager sync push [<kind>] [<path>] [--if-match <sha256>]`

Upload one lock file, or run without arguments to upload known lock files in the current directory. Git-tracked files are not uploaded.

```sh
# Push all known lock files in the current directory
outfitting-manager sync push

# Push one lock file
outfitting-manager sync push nix ./saved-flake.lock
```

| Argument or option    | Description                                                                    |
| --------------------- | ------------------------------------------------------------------------------ |
| `<kind>`              | Lockfile type. Omit it or use `all` to push all known local lock files.        |
| `<path>`              | File to push. Required for one kind; omit when pushing all kinds.              |
| `--if-match <sha256>` | Push only if the saved version still has this SHA-256 hash. Use with one kind. |

## `pull`

**Syntax:** `outfitting-manager sync pull [<kind>] [<out-path>]`

Download one saved lock file, or omit the kind (or pass `all`) to download every saved type. If you do not provide a path, files are written to their default locations in the current directory. Pull refuses to replace a Git-tracked file, but it overwrites other existing files without prompting.

```sh
# Download a saved lock file to a specific location
outfitting-manager sync pull nix ./backups/saved-flake.lock
```

## `list`

**Syntax:** `outfitting-manager sync list`

List the saved lock file types for this machine.

```sh
outfitting-manager sync list
```

## `history`

**Syntax:** `outfitting-manager sync history [<kind>]`

Show saved versions of one lock file. Omit the type or use `all` to show all types.

```sh
outfitting-manager sync history nix
```
