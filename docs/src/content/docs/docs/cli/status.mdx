**Syntax:** `outfitting-manager status`

Show the active platform, profile, configuration file, machine ID, and source status. `status` does not change your configuration or packages, fetch a source, or contact the lockfile service.

```sh
outfitting-manager status
```

| Platform | Selected profiles                     |
| -------- | ------------------------------------- |
| Linux    | One Linux profile.                    |
| macOS    | One macOS profile.                    |
| Windows  | One or more comma-separated profiles. |
