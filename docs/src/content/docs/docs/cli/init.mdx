**Syntax:** `outfitting-manager init [flags]`

`init` prepares this machine for Outfitting and checks the selected source. Remote sources are refreshed by default. It does not change installed packages.

```sh
# Set up the configured source
outfitting-manager init

# Select a profile and use an already initialized source without refreshing it
outfitting-manager init --profile workstation --no-refresh
```

| Option                | Description                                                                       |
| --------------------- | --------------------------------------------------------------------------------- |
| `--machine-id <id>`   | Use a different machine ID. By default, one is derived from your user and system. |
| `--repo <path>`       | Use a local source directory for this command.                                    |
| `--profile <profile>` | Select a profile. Windows accepts comma-separated profiles.                       |
| `--no-refresh`        | Use the current source without refreshing it.                                     |

## Platform behavior

| Platform | What `init` prepares                                                        |
| -------- | --------------------------------------------------------------------------- |
| macOS    | The selected source. It does not change Homebrew or activate Nix.           |
| Linux    | The selected source. It does not install packages or activate Home Manager. |
| Windows  | The selected source. It does not install packages.                          |
