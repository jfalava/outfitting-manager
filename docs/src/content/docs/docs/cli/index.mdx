Use `outfitting-manager` to set up a machine, manage declared packages, compare installed packages with your configuration, and sync state. Available commands depend on your platform.

Install the CLI with the platform-specific commands on the [Installation](/docs/installation/) page.

## Global options

| Option                  | Description                                                                                                                  |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `--config <path>`       | Use a specific `config.toml`. May appear before or after the command. You can pass it once. Also set by `OUTFITTING_CONFIG`. |
| `--help`, `-h`          | Show help for the command.                                                                                                   |
| `--version`, `-v`       | Show the CLI version.                                                                                                        |
| `--wizard`              | Run the selected command in interactive mode.                                                                                |
| `--completions <shell>` | Print completions for `bash`, `zsh`, `fish`, or `sh`.                                                                        |
| `--log-level <level>`   | Set the minimum log level: `all`, `trace`, `debug`, `info`, `warn`, `warning`, `error`, `fatal`, or `none`.                  |

## Commands

| Command                                                    | Availability   | What it does                                            |
| ---------------------------------------------------------- | -------------- | ------------------------------------------------------- |
| [`init`](/docs/cli/init/)                                  | All platforms  | Set up local state and check the selected source.       |
| [`apply`](/docs/cli/apply/)                                | All platforms  | Install packages declared for the selected profile.     |
| [`validate`](/docs/cli/validate/)                          | All platforms  | Check configuration and declared files.                 |
| [`config`](/docs/cli/config/)                              | All platforms  | Set up machine configuration or create a repo manifest. |
| [`source`](/docs/cli/source/)                              | All platforms  | Print the selected source path.                         |
| [`status`](/docs/cli/status/)                              | All platforms  | Show the active configuration and source status.        |
| [`diff`](/docs/cli/diff/)                                  | All platforms  | Compare installed packages with declarations.           |
| [`update`](/docs/cli/update/)                              | All platforms  | Upgrade installed packages.                             |
| [`nix`](/docs/cli/nix/)                                    | macOS, Linux   | Build or activate the configured Nix profile.           |
| [`sync`](/docs/cli/sync/)                                  | All platforms  | Push, pull, and inspect saved state.                    |
| [`fonts`](/docs/cli/fonts/)                                | All platforms  | List and manage private fonts.                          |
| [`provision`](/docs/cli/provision/)                        | All platforms  | Deploy the Outfitting service.                          |
| [`self-update`](/docs/cli/self-update/) (alias: `upgrade`) | All platforms  | Update the CLI.                                         |
| [`homebrew`](/docs/cli/homebrew/)                          | macOS          | Inspect the observed Homebrew inventory.                |
| [`recover`](/docs/cli/recover/)                            | macOS, Linux   | Resume an interrupted Nix update.                       |
| [`winget`](/docs/cli/winget/)                              | Windows        | Install or remove WinGet packages.                      |
| [`scoop`](/docs/cli/scoop/)                                | Windows        | Install or remove Scoop packages.                       |
| [`backups`](/docs/cli/backups/)                            | macOS, Windows | Run guarded Rustic backups and inspect retention.       |
