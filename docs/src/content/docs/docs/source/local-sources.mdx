title: Local sources
description: Use a local checkout for machine configuration and package declarations.

Use a local source when you want Outfitting to read declarations from a checkout on this machine. Add its path to `config.toml`:

```toml
[source]
path = "../dotfiles"
```

Relative paths start from the directory containing `config.toml`. The checkout must already exist. Outfitting reads it in place, so local edits are available to the next command.

To use a different checkout for initialization without changing `config.toml`, pass `--repo`:

```sh
outfitting-manager init --repo ~/src/dotfiles
```

For a Git repository source, see [Remote sources](/docs/source/sparse-artifacts/).
