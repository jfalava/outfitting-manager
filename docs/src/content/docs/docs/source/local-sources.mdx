---
title: Local setup files
description: Use files in a local folder or checkout for machine setup.
sidebar:
  order: 10
---

Use a local folder or checkout when your setup files are already on this machine. Point Outfitting to it in `config.toml`:

```toml
[source]
path = "../dotfiles"
```

Relative paths start from the directory containing `config.toml`. The folder must already exist. Outfitting reads files from it directly, so local edits are available to the next command.

To use a different folder for one `init` command without changing `config.toml`, pass `--repo`:

```sh
outfitting-manager init --repo ~/src/dotfiles
```

For setup files stored in a Git repository, see [Remote Git repository](/docs/source/sparse-artifacts/).
