`outfitting-manager backups` is available on macOS (Apple silicon or Intel), Windows (x64), and Linux (x64 or arm64, including NixOS).

Before the first backup, make sure you have:

- [Outfitting Manager installed](/docs/installation/) and Rustic 0.10 or later available on your `PATH`.
- A backup profile for this machine's platform, with a repository and source folders configured. See [Set up backups](/docs/backups/setup/).
- Read access to every configured source folder.
- A local `[backups.credentials]` mapping, set directly or imported from manifest `backups.credentials`, with exactly `access-key`, `secret-key`, `repository-password`, and `alert-token` mapped to distinct, nonblank, control-free native service names. There are no defaults; configuration stores names, never secret values.
- Repository credentials stored under those names in macOS Keychain, Windows Credential Manager, or the Linux Secret Service for the scheduled OS account.
- On Linux, an unlocked Secret Service (such as GNOME Keyring) reachable from the systemd user manager without a login session. See [Keep the Secret Service unlocked on Linux](/docs/backups/setup/#keep-the-secret-service-unlocked-on-linux).
- A local `alertUrl` pointing to a canonical HTTPS `/v1/alerts` endpoint plus a stored `alert-token` with an enabled Canary credential policy, or explicit `alertsDisabled = true` with `alertUrl` omitted. The server policy owns the sender and complete recipient list. Opt-out skips alert-token lookup and checks, but still requires its service-name mapping. Missing settings block backup commands before native access.

If you generate a scheduled task, use the same logged-in account that stores the credentials. On Windows, that account must stay logged in; locking the session is fine. On Linux, enable lingering for that account so its timer runs without a login. The schedule also requires absolute paths to both the Outfitting Manager and Rustic executables.

Check the profile and credentials before running a backup:

```sh
outfitting-manager backups doctor
outfitting-manager backups secrets check
```
