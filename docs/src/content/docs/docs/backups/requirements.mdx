<Aside type="note" title="Rustic wrapper">
`outfitting-manager backups` is a wrapper around **Rustic**. To use it, you must have Rustic installed on your machine and have credentials for your remote storage bucket.
</Aside>

## 1. Supported platforms

- **macOS** (Apple silicon and Intel)
- **Windows** (x64)

> **Note:** Backups are not supported on Linux.

## 2. Installed tools

- **Rustic:** The `rustic` binary (version 0.9 or later) must be installed and in your system `PATH` (or specified via the `BACKUP_RUSTIC` environment variable).
- **PowerShell:** On Windows, `powershell.exe` or `pwsh.exe` is required for process checks and secret imports.

Check that Rustic is available:

```sh
rustic --version
```

## 3. Native credentials

Outfitting Manager stores your repository keys in the operating system's native secret store:

- **macOS:** macOS Keychain
- **Windows:** Windows Credential Manager

Credentials are never stored in plaintext files, repository commits, or CLI flags.

### Required secrets

Configure four credentials for each machine:

| Secret | Description |
| ------ | ----------- |
| `access-key` | Storage access key ID (e.g. AWS S3 or Cloudflare R2). |
| `secret-key` | Storage secret access key. |
| `repository-password` | Encryption password for the Rustic repository. |
| `alert-token` | Bearer token for failure alert webhooks. |

### Setting credentials

Set each secret interactively in your terminal:

```sh
outfitting-manager backups secrets set access-key
outfitting-manager backups secrets set secret-key
outfitting-manager backups secrets set repository-password
outfitting-manager backups secrets set alert-token
```

Verify that all secrets are accessible:

```sh
outfitting-manager backups secrets check
```

## 4. Configuration in your setup files

Your repository manifest (`outfitting.json`) or local `config.toml` must declare your backup profile and what folders to back up.

### Manifest declaration (`outfitting.json`)

```json
{
  "schema": 2,
  "backups": {
    "defaultProfile": "ultramar",
    "profiles": {
      "ultramar": {
        "platform": "macos",
        "files": [
          "backups/common.toml",
          "backups/ultramar.toml"
        ]
      }
    }
  }
}
```

Import your manifest into `config.toml` using the configuration wizard:

```sh
outfitting-manager config wizard --manifest system/macos/outfitting.json
```

### Backup TOML fragments

Your declared TOML files specify the repository location, retention rules, and snapshot folders:

```toml
[repository]
repository = "opendal:s3"

[repository.options]
bucket = "my-backup-bucket"
endpoint = "https://<account-id>.r2.cloudflarestorage.com"
region = "auto"

[forget]
keep-daily = 7
keep-weekly = 4
keep-monthly = 12

[[backup.snapshots]]
name = "documents"
sources = ["~/Documents"]
tags = ["documents"]
skip-if-unchanged = true
```

## 5. User permissions

- **File access:** The user running the backup must have read access to the folders being backed up.
- **Scheduled tasks:** Scheduled jobs (via LaunchAgents on macOS or Task Scheduler on Windows) must run under your logged-in user account so they can access your Keychain or Credential Manager.
